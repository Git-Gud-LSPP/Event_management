## Flows walked in the browser

1. Landing → explorer: picked 6 modules → "Start free with this stack" → `/signup?plan=growth` with the stack shown.
2. Sign up: invalid email shows an inline error. Valid email moves to step 2 (name, password, show/hide).
3. **Blocked here by environment, not code:** MongoDB isn't installed on this machine (`Program Files\MongoDB\Server\8.0` is empty) and Docker isn't running, so `POST /auth/register` can't complete. The code path is the existing, unchanged `authApi.register`.
4. Onboarding (local stand-in session): role → event types → team size → recommended stack. Roadmap picks from the site (Check-in, Ticketing, Payments) were moved to a notify list instead of using trial slots. "Continue on Free" kept the 5 picks as locked add-ons.
5. Locked module: `/floorplan` showed the preview (bullets, clip, plan note), then "Try it free for 14 days" → trial dialog → module unlocked in place. Sidebar shows "Trial · 14d".
6. Marketplace: slot meter 5/5, Included/On/Add/Notify me states.
7. Slot limit: a full Starter plan + adding Floor Plan → swap list with last-opened dates, then "Upgrade to Growth".
8. Checkout (test mode): an empty submit shows 3 inline errors. Test card 4242… → "You're on Growth", Floor Plan on, proration credit $23 correct.
9. Plan & billing: downgrade to Starter → pick-5-to-keep dialog → pending banner → "Keep Growth" undo. Cancel → reason → seasonal-aware consequences, with keep and cancel weighted equally.

Unit tests: `src/billing/plan.test.ts` covers plan recommendation, entitlement, slot ordering after downgrade, swap, the add limit and trial expiry. 14/14 pass across the suite.
